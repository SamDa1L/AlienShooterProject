# 项目目录结构说明

本文档只说明当前项目的目录结构和每个目录可以存放的内容，不包含玩法设计、技术施工步骤或具体功能实现方案。

目录结构来源：`Docs/总设计文档/GDD_污染区撤离_Codex版.md` 中的 `3.4 项目目录结构`。

## 一、总目录原则

| 目录 | 说明 |
|---|---|
| `Assets/Game` | 正式业务资源目录，当前项目原创代码、场景、预制体、配置、美术、音频等正式内容都放在这里。 |
| `Assets/ProjectRef` | 参考模板资源目录，只用于分析、临时验证和对照，不作为正式业务目录，不上传 Git。 |
| `Assets/ArtTemplate` | 临时美术资源池目录，用于导入和筛选大量外部美术资源，不作为正式业务目录，不上传 Git。 |

## 二、正式业务目录总览

```text
Assets/
  ArtTemplate/
  Game/
    Art/
    Audio/
    Materials/
    Prefabs/
    Scenes/
    Scripts/
    ScriptableObjects/
    Tests/
  ProjectRef/
  TmpTests/
```

`Assets/ArtTemplate` 中只有确认使用的美术资源，才允许整理后移动到 `Assets/Game/Art` 下对应子目录。

`Assets/Game/Tests` 只存放测试场景，不存放测试代码。临时测试代码统一放入 `Assets/TmpTests`，且不上传 Git。
